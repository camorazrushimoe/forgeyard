# Domain modeling

When terms drift, update `CONTEXT.md` in the project checkout:

- name → meaning → what it is not

If a decision is durable, add an ADR (`docs/adr/NNNN-title.md`) with context, decision, consequences.
Do not invent a second glossary in chat.
